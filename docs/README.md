# Mini-R1 学习文档

这是一套**给初学者看的**项目文档。目标：一个没接触过大模型训练的人，照着读完 + 动手做完，
能说清楚「这个项目每一行代码在干什么、为什么这么写」，并且能自己把它跑起来。

> 你不需要事先懂 Transformer、不需要懂分布式训练、不需要用过 GPU 服务器。
> 需要的是：会一点 Python，会用命令行（`cd` / `ls` / `python xxx.py` 这个级别）。

## 阅读前的一句话总结

这个项目做的事情，用一句话说：

> 从零手写一个 4 亿参数的小型 GPT，先用 50 亿 token 的网页文本教它「会说英语」，
> 再用 20 万条对话教它「会听指令」，最后用数学题 + 强化学习教它「会一步步推理」，
> 并在 GSM8K 小学数学题上量化每一步到底涨了多少分。

三个阶段的名字：**预训练（pretrain）→ 监督微调（SFT）→ 强化学习（GRPO）**。
这是当今所有推理模型（DeepSeek-R1、o1 这类）的标准路线，只是规模缩小到了单张显卡能跑完。

## 关于命令里的路径

本项目的服务器上，代码固定放在 `/root/Test/mini-r1`。文档里为了简洁，常用 `$PROJ` 指代它：

```bash
export PROJ=/root/Test/mini-r1     # 先定义，后面就能用 $PROJ 了
cd $PROJ
```

你在别的机器上复现时，把 `$PROJ` 换成你自己的目录即可 —— 但注意
[03-环境搭建](03-环境搭建.md) 里提到的几个写死了路径的地方。

服务器地址、端口、密码这类信息**不在本目录**（本目录会公开到 GitHub）。
本项目的真实连接参数见 [AGENTS.md](../AGENTS.md) §3，而下面这套文档教你的是**通用做法**。
